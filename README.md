WeatherWise — Frontend Ui/Ux With AI/Generative Tools

Welcome to the frontend repository of **WeatherWise**, a modern, space-themed weather dashboard. 

> Note : As a software engineer mainly focused on **Backend Architecture & System Logic**, I Using Generative AI/Modern UI tools to accelerate the frontend development process. My role here was acting as the Back-end Developer
> ensuring the Security And Logic Flow Smoothly.

---

##  Tech Stack & Design Aesthetics
* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS (Dark Mode / Cosmic Aesthetic)
* **Animations:** Framer Motion (Smooth layout transitions)
* **Icons:** Lucide React

---

 Data Flow: How Frontend Receives JSON from Backend

Since this project uses a **Decoupled (Separated) Architecture**, the React frontend does not communicate with the database directly. Instead, it securely consumes JSON data from the Laravel Backend API.

## How To Run This Project
1. Clone This Repo
    git clone https://github.com/PottaAditya/nama-repo-frontend.git
2. Install dependencies
    Npm Install
3. Run The Development
   Npm Run Dev
